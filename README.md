# MuViSU retreat website

Quarto website for the MuViSU two-day retreat, modelled on [oceaniar-2026](https://github.com/StatSocAus/oceaniar-2026).

Edit `index.qmd`, `program.qmd`, `venue.qmd`, then run `quarto render` (output in `docs/`) or `quarto preview`. Pushes to `main` publish to GitHub Pages (`gh-pages` branch) via GitHub Actions.
